# libasm

Proyecto de 42: reimplementación en ensamblador x86-64 (NASM, sintaxis
Intel) de varias funciones de la libc — `strlen`, `strcpy`, `strcmp`,
`write`, `read`, `strdup` — empaquetadas en `libasm.a`.

Bonus: `ft_atoi_base` y funciones sobre listas enlazadas
(`push_front`, `size`, `sort`, `remove_if`) también en ensamblador.

Sujeto completo en `libasm.pdf`.
